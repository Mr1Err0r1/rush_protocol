# Rush Protocol — Blackglass Casino

**Rush Protocol** — прототип тактической 3D-игры на Godot 4.7 о многоэтажном казино. Выберите роль, соберите ограниченный набор снаряжения, пройдите вымышленный досмотр, следите за фишками и подозрением и попытайтесь переиграть соперничающие фракции в башне казино.

> **Статус:** активный прототип, до релиза. В репозитории нет законченной или готовой к выпуску игры. Покер и блэкджек пока не реализованы как полноценные игровые столы. Оружие, контрабанда, обман и мошенничество в казино — вымышленные игровые механики; проект не содержит инструкций для реального мира.

## Что уже есть в прототипе

- Пятиэтажная башня казино, собираемая во время запуска из 3D-геометрии Godot, с тематическими этажами и зонами лифтов.
- Пошаговый выбор персонажа: сначала фракция, затем только доступные роли этой фракции; последняя выбранная роль запоминается.
- Ресурсы персонажей для мафии, гильдии ассасинов, мирных жителей, военных, правительства/следователей и элиты казино.
- Стартовые характеристики и гарантированное снаряжение персонажей, правила контрабанды и наборов экипировки.
- Вымышленный досмотр на входе, системы подозрения и внимания, инвентарь игрока, фишки, рискованные действия, гаджеты и оружие.
- Основа главного меню, настроек, сохранений, HUD, одиночной игры/ИИ и сетевого режима.

Часть систем пока является прототипом или только основой на данных. Пентхаус подаёт сигнал о встрече с боссом, однако полноценная арена, цепочка заданий и законченный интерфейс босса ещё не готовы. Правила покера и блэкджека, ИИ дилера, способности фракций, блокировка доступа к этажам, баланс и финальная визуальная полировка требуют дальнейшей работы. Подробности и ограничения описаны в [полном обзоре игры](GAME_OVERVIEW.ru.md).

## Требования и запуск

- Godot **4.7 или новее** (проект рассчитан на Godot 4.x).
- Git, если вы клонируете репозиторий из командной строки.

```bash
git clone https://github.com/Mr1Err0r1/rush_protocol.git
cd rush_protocol
```

Импортируйте и откройте `project.godot` в Godot, затем запустите проект. Главная сцена открывает меню. В одиночном режиме сначала выберите фракцию, затем роль из этой фракции, а после настройте пол и снаряжение; пункты меню могут меняться по мере разработки.

Для headless-импорта редактора (исполняемый файл Godot должен быть доступен через `PATH`):

```bash
godot --headless --editor --path . --quit
```

Эта проверка импорта не заменяет полноценное интерактивное тестирование или аудиовизуальную проверку качества. Скрипт `scripts/test/run_headless_smoke.sh` автоматически проверяет запуск сцен и ошибки движка, но не заменяет игровое и аудиовизуальное QA.

## Управление

Доступность действий зависит от сцены и фазы матча. Стандартные прототипные клавиши:

| Ввод | Действие |
|---|---|
| `W A S D` | Движение |
| Мышь | Обзор / камера |
| `Shift` | Бег |
| `Пробел` | Прыжок |
| `1`–`4` | Использовать соответствующий предмет на панели |
| Левая кнопка мыши | Рискованное действие (если доступно) |
| `T` | Выбрать цель |
| `Enter` | Завершить ход |
| `V` | Прототипная атака |
| `F5` | Переключить режим камеры |
| `Esc` | Пауза / назад, в зависимости от экрана |
| `E` | Зарезервированное взаимодействие; сейчас лифт срабатывает при входе в зону |

Настройки и переназначение клавиш могут различаться между экранами и всё ещё дорабатываются.

## Структура репозитория

```text
autoload/               Глобальные менеджеры (игра, сохранения, язык, предметы, звук, события)
core/                   Логика персонажей, игроков, матчей и риска
resources/characters/   Данные персонажей и фракций
resources/items/        Определения предметов
scenes/world/           Сцены меню, игрового мира и матча
scripts/world/          Настройка матча и процедурная башня казино
scripts/ui/              Меню, выбор персонажа и HUD
scripts/items/           Поведение предметов
```

## Релизы

**Стабильного или готового к выпуску релиза пока нет.** Репозиторий находится в активной разработке прототипа. Выбор фракции и персонажа реализован, но требует интерактивного QA. До релиза необходимо проверить основной игровой цикл за столами, ключевые игровые сценарии, платформы, лицензию и воспроизводимую сборку. Текущую ветку `main` не следует считать законченной игрой или релизной сборкой.
